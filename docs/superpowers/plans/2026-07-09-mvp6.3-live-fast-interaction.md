# MVP6.3 Audio-Native Live Fast Interaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct MVP6.3 so the live fast answer path is audio-native, exposes Thinker/Fast Interaction TTFT and latency waterfall metadata, and keeps ASR-text Fast Interaction only as an explicitly labeled fallback/degraded/debug path.

**Architecture:** MVP6.3 keeps the ADR-017 foreground skeleton: Fast Interaction emits route evidence and a reply candidate, Router owns the route, and Fast Foreground Gate owns display/discard/fallback. The primary live path becomes `TURN_INGRESS_COMMITTED(audio) -> audio-native fast_interaction adapter -> FAST_INTERACTION_OUTPUT_EMITTED -> Router -> Fast Foreground Gate`; ASR may run in parallel and may feed an `asr_text_fallback` adapter mode only when explicitly configured. Timing is metadata-only and replay-safe: TTFT/full-response/parse/emit fields are recorded once and replayed as recorded, never recomputed by rerunning providers.

**Tech Stack:** Python 3, dataclasses, existing adapter capability/profile pattern, existing `InMemoryEventJournal`, existing direct HTTP injected-opener transport pattern, metadata-only local debug model I/O, `./scripts/test`.

## Ground Rules

- Do not implement a post-Router `FastReplyAdapter`.
- Do not make Router perform complex task reasoning.
- Do not make fast replies `SemanticCommitment`.
- Do not mutate SlowTask facts/current-plan facts/tool status/confirmation state from Fast Interaction.
- Do not implement real TTS or tool/external side effects.
- Do not write raw audio, raw prompt, provider request body, provider response body, diagnostics, secrets, local replay cache, local paths, or unredacted real input into committed artifacts.
- Do not call live providers in tests. Use fake/injected transports only.
- Do not run provider calls during deterministic replay.
- Run Python tests through `./scripts/test`, not direct `pytest`.

- [ ] **Step 3: Implement `adapter_timing.py`**

Create `AdapterTimingSnapshot` and `AdapterTimingRecorder`:

```python
@dataclass(frozen=True)
class AdapterTimingSnapshot:
    adapter_start_offset_ms: int
    provider_request_start_offset_ms: int | None
    provider_first_chunk_offset_ms: int | None
    provider_full_response_offset_ms: int | None
    adapter_event_emit_offset_ms: int
    provider_ttft_ms: int | None
    provider_full_response_ms: int | None
    provider_generation_ms: int | None
    stream_decode_ms: int
    parse_validate_emit_ms: int
    total_ms: int
    timing_mode: str
    ttft_available: bool
    ttft_source: str

    def to_prefixed_metadata(self, prefix: str) -> dict[str, int | bool | str | None]:
        return {
            f"{prefix}_adapter_start_offset_ms": self.adapter_start_offset_ms,
            f"{prefix}_provider_request_start_offset_ms": self.provider_request_start_offset_ms,
            f"{prefix}_provider_first_chunk_offset_ms": self.provider_first_chunk_offset_ms,
            f"{prefix}_provider_full_response_offset_ms": self.provider_full_response_offset_ms,
            f"{prefix}_adapter_event_emit_offset_ms": self.adapter_event_emit_offset_ms,
            f"{prefix}_provider_ttft_ms": self.provider_ttft_ms,
            f"{prefix}_provider_full_response_ms": self.provider_full_response_ms,
            f"{prefix}_provider_generation_ms": self.provider_generation_ms,
            f"{prefix}_stream_decode_ms": self.stream_decode_ms,
            f"{prefix}_parse_validate_emit_ms": self.parse_validate_emit_ms,
            f"{prefix}_total_ms": self.total_ms,
            f"{prefix}_timing_mode": self.timing_mode,
            f"{prefix}_ttft_available": self.ttft_available,
            f"{prefix}_ttft_source": self.ttft_source,
        }
```

`AdapterTimingRecorder` must accept `turn_ingress_monotonic_ms` and `now_ms`, record monotonic integer milliseconds, derive TTFT only when first chunk exists, and reject unsafe prefixes outside `{"thinker", "fast_interaction"}`.
