## Cross-card invariants

ADRs govern; models use adapters; state is journaled; replay is deterministic;
Controller owns ingress; one Pump owns order; evidence is not Router authority;
PCM stays disabled; release tests stay isolated; refs reveal no payload; raw
audio/trace, secrets, real input, and provider bodies stay out.

## Per-card verification policy

Verify first, write RED, change only `Create:`/`Modify:` paths, run focused,
overlap, and diff gates, then capture evidence. Mark `verified` only when green.
`Regression test:` paths are read-only; successors wait for predecessors.

## Stop, retry, and rollback conditions

Stop on ADR/dependency/hash/staging conflict, scope expansion, sensitive
artifact, or failed gate. Preserve evidence; never reset user work. Use
card-local rollback or request direction if scope cannot be isolated.

failure and leave the package `blocked`, never `verified`. A
deterministic repository safety audit finds no network, secret, raw artifact, placeholder, or false claim;
the pre/post worktree comparison preserves prior changes; independent review
gives green spec/quality verdicts; the final acceptance-criterion mapping ties
all 23 criteria to evidence.
